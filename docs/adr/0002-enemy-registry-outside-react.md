# Покадровое состояние врагов — в мутабельном реестре вне React и zustand

Прогресс, позиция и здоровье каждого врага живут в модульном `Map` (`src/game/enemies.ts`):
`<Enemy>` пишет туда в `useFrame`, `<Tower>` читает оттуда в своём `useFrame`. Zustand
хранит только то, что видит UI и что меняется событиями: id живых врагов, деньги, жизни,
волну, статус, башни. Позиции в React state дали бы ререндер дерева 60 раз в секунду,
а ref внутри `<Enemy>` недоступен соседнему `<Tower>`, поэтому нужен общий реестр.

## Considered Options

- **`hp` в zustand, остальное в реестре** — попадание событийно, стор бы выдержал, но
  состояние боя одного врага оказалось бы размазано по двум местам.
- **Один `useFrame` в `<Enemies>` двигает всех и считает урон** — работает, но башни
  перестают быть самостоятельными компонентами, и паттерн хуже переносится в тайкун.
