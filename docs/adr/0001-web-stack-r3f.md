# Веб-стек на React Three Fiber, а не игровой движок

TD — разминка перед большим проектом (изометрический соц-тайкун с бэкендом), поэтому
стек выбран по переносимости в него: Vite + React 19 + TypeScript + three.js +
@react-three/fiber + drei + zustand, деплой на Vercel. Подсистемы TD (движение по кривой,
постройка в слот, поиск цели, волны, экономика) почти дословно переезжают в тайкун,
а результат открывается по ссылке, без скачивания `.app`.

## Considered Options

- **Godot** — редактор сцен и чуть более быстрый старт, но GDScript и его ноды не
  переносятся в тайкун на React. При режиме «несколько часов в неделю» выученный и
  выброшенный движок — самая дорогая ошибка.
- **Unity** — 10–15 ГБ ради задачи, которой это не нужно.
- **Unreal** — 100+ ГБ, деградированный опыт на Mac ARM; Nanite/Lumen решают
  несуществующие здесь проблемы.

Решающее ограничение машины: M1 Pro, 16 ГБ RAM, около 40 ГБ свободного диска.
